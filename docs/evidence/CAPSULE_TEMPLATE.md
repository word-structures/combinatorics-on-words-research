# Micro-Capsule Evidence Template

**Promotion Trigger:** A scratch run deserves permanent evidence only if it:
- provides an exact refutation;
- changes CURRENT_FOCUS;
- supports a future accepted claim;
- preserves a reusable finite certificate/witness;

*Everything else remains scratch.*

## RESULT_ID: [ID]
* **question**: [What was asked?]
* **exact scope**: [Finite bounds or conditions tested]
* **source commit**: [Commit hash where script was run, or UNKNOWN]
* **script filename + sha256**: [Name of script and its hash]
* **command**: [Exact execution command]
* **runtime/environment**: [Node/C++ version, runtime conditions]
* **input identity**: [Input data, e.g., seed word]
* **raw output**: [Location of output file]
* **witness**: [Exact finite counterexample or certificate]
* **independent check + independence axes**: [Details of verification]
* **known shared assumptions**: [Assumptions e.g. K >= 2 standard aa2f check]
* **claim boundary**: [What this proves/refutes, explicitly bounding the claim]
* **storage class**: PERMANENT EVIDENCE
