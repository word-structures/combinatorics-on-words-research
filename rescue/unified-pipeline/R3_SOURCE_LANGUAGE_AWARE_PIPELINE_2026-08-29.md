# R3 SOURCE-LANGUAGE-AWARE MORPHISM SEARCH
**Date:** 2026-08-29

## 1. The Failure of Clique-Search
Testing all arbitrary pairs or subsets of macro-blocks demands connectivity that infinite morphic words do not possess. An `aa2fr` infinite word generated by a morphism inherits its structure strictly from a parent source language (e.g., an existing square-free or abelian-square-free word over Gamma).

## 2. Source-Language-Aware Local Gate
Let $x$ be the chosen candidate source word over Gamma.
To verify local validity up to the bound $K \le 2L - 1$ (which requires $4L-3$ memory per the exact lemma):
- The maximum length of a local violation is $4L-2$.
- This violation spans at most ceil((4L-2)/L) = 4 macro-blocks.
- Therefore, we do **NOT** need to check all block pairs or triplets. We only need to check the exact mapped blocks corresponding to the **length-2, length-3, and length-4 factors** that actually exist in the source word $x$.

## 3. The Reconstructed Pipeline
1. **Source Selection:** Select a parent template $x$ (such as the $h_6$ word, though not presuming it is the only/optimal one).
2. **Factor Extraction:** Extract all unique factors of length $\le 4$ from $x$.
3. **Target Assignment:** Map Gamma to {a,b,c}^L using a bounded solver over the AFE cutset.
4. **Local Verification:** Only evaluate the $4L-3$ memory check on the specific block sequences dictated by the source factors.
5. **Global Verification:** Pass the successfully assigned support vectors to the Paper 4 19-family compiler for long-range certification.

This structurally limits the combinatorial explosion and aligns the finite graph precisely with the external infinite controller required to avoid ordinary squares.
