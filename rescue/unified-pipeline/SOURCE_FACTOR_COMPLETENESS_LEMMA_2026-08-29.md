## 1. Minimal Required Factor Length
As derived in the Exact Local Window and Block Span Theorem, for a uniform target assignment of block length L >= 4 and a local verification bound of K <= 2L - 1, the maximum newly completed violating factor spans at most 5 macro-blocks.
Therefore, the local constraint solver must evaluate the target assignment G(w) for every source factor w in F_5(x).

## 2. Completeness of the Factor Extractor

h6(a) = ace, h6(b) = adf, h6(c) = bdf, h6(d) = bdc, h6(e) = afe, h6(f) = bce.

We define a stabilization procedure for extracting F_m(x):
1. Compute the sequence of words W_n = h6^n(a).
2. For each n, compute the set S_n of all factors of W_n of length <= m.
3. If S_n = S_{n-1}, the factor language has empirically stabilized for length m. Since h6 is uniform and primitive, this stabilization is global.
