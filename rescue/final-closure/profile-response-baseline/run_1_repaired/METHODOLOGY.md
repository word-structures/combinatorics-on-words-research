# METHODOLOGY

## SFT Construction
The common-memory transition graph was generated by constructing states avoiding Abelian squares of half-length K in {2...h-1}. An edge is added if the resulting 2h-word avoids these conditions (which is mathematically equivalent to the target state avoiding them, as proven in EDGE_EQUIVALENCE_PROOF.md). 

## Profile Classification
Parikh profiles were robustly classified by three separate indexing loops (first half, second half, and a fresh loop) and canonicalized by descending order.

## Asymptotic Variance
The asymptotic variance 'a' was computed using two distinct methods on the essential dominant strongly connected component:
1. **Green-Kubo Poisson Solver**: Evaluated the full covariance sum by analytically iterating the transition matrix on the zero-mean observable.
2. **Normalized Moment DP**: Ran for 3000 steps, extracting the variance slope over windows [1000, 2000] and [2000, 3000].

## Invariance and Equivalences
The dominant SCC was cleanly extracted using Tarjan's algorithm, and the Perron root was computed rigorously via 1000 power iterations. No previously certified numerical values were assumed or fed into the loop; all values emerged directly from graph structures.
