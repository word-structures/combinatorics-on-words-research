# Carry–Curvature / Mechanical Geometry v0.1

Uniform-block occurrence curvature is the discrete derivative of a binary carry word. That carry word is exactly a rational mechanical word of slope `(K mod L)/L`.

This unifies curvature, midpoint routing, and Abelian k-power motif chains under a finite rotation modulo L.

Mechanical-word theory itself is classical; novelty of the application is unresolved.
