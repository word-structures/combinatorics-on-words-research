## 0. Result in one sentence

For long half-periods \(K\ge L\), the exact character-boundary contribution
does not require the literal identities of the boundary blocks.

It requires only a finite collection of **segment Parikh data at the actual
cutpoints**, together with the full block profiles where those blocks also
participate in the long-range bulk sum.

Those data can be grouped into cut-profile families and generated by
coefficient extraction from the character-level safety operators.

---

# 1. Recall the long-period decomposition

For

\[
K=qL+r,\qquad q\ge1,\quad0\le r<L,
\]

and start offset

\[
s=m_0L+i_0,
\]

write

\[
s+K=m_1L+i_1,\qquad
s+2K=m_2L+i_2.
\]

Let

\[
c_0=m_1-m_0-q,\qquad
c_1=m_2-m_1-q,
\]

so \(c_0,c_1\in\{0,1\}\).

The bounded-defect theorem gives

\[
F(s)-2F(s+K)+F(s+2K)=D_q+E
\]

with

\[
D_q=
\sum_{t=m_1}^{m_1+q-1}\Psi(b_t)
-
\sum_{t=m_1-q}^{m_1-1}\Psi(b_t),
\]

and

\[
E=
c_1\Psi(b_{m_1+q})
-c_0\Psi(b_{m_0})
+X_{m_0}(i_0)
-2X_{m_1}(i_1)
+X_{m_2}(i_2).
\]

# 2. Theorem CP1 — three-fragment sufficiency

Define

\[
A=
X_{m_0}(i_0)-c_0\Psi(b_{m_0}),
\]

\[
B=
X_{m_1}(i_1),
\]

and

\[
C=
c_1\Psi(b_{m_1+q})+X_{m_2}(i_2).
\]

Then

\[
\boxed{
E=A-2B+C.
}
\]

Therefore, for a fixed long-period cutpoint geometry, exact character-level
boundary information enters the Abelian-square condition only through the
three Parikh vectors \(A,B,C\).

The square condition is

\[
\boxed{
D_q+A-2B+C=0.
}
\]

All literal order information outside the cut fragments is irrelevant to this
particular long-period test.

This statement is exact.

# 3. Geometries are finite

For \(K=qL+r\), the local geometry is determined by

\[
(i_0,r)\in\{0,\ldots,L-1\}^2.
\]

From \((i_0,r)\), the values

\[
i_1,\ i_2,\ c_0,\ c_1
\]

are determined arithmetically.

Hence there are only

\[
\boxed{L^2}
\]

long-period cutpoint geometries, independent of \(q\) and therefore
independent of the size of the half-period.

This is stronger operationally than a half-period-by-half-period catalogue:
the local character physics saturates once the block length is fixed.

# 6. Cut-profile descriptors

When a boundary block also contributes its whole profile to \(D_q\), the
fragment value must remain correlated with that whole profile.

For a block \(b\) and cut position \(i\), define its cut-profile descriptor

\[
\boxed{
C_i(b)=
\left(
\Psi(\operatorname{pref}_i b),
\Psi(\operatorname{suf}_{L-i}b)
\right).
}
\]

The full profile is the sum of the two components, so \(C_i(b)\) simultaneously
contains:

- the local fragment profile needed by \(E\);
- the whole block profile needed by \(D_q\).

This is the natural family-level boundary descriptor for the long-period
interface.

# 7. Theorem CP2 — polynomial universal descriptor bound

For an alphabet of size \(d\), the number of possible Parikh vectors of a
length-\(n\) factor is

\[
\binom{n+d-1}{d-1}.
\]

Therefore the number of possible cut-profile descriptors at cut \(i\) is at
most

\[
\binom{i+d-1}{d-1}
\binom{L-i+d-1}{d-1}.
\]

Summing over all cuts,

\[
\boxed{
N_{\rm cut}(L,d)
\le
\sum_{i=0}^{L}
\binom{i+d-1}{d-1}
\binom{L-i+d-1}{d-1}
=
\binom{L+2d-1}{2d-1}.
}
\]

The last equality is Vandermonde convolution.

For the ternary case,

\[
\boxed{
N_{\rm cut}(L,3)\le\binom{L+5}{5}.
}
\]

Thus at \(L=40\),

\[
\boxed{
N_{\rm cut}(40,3)
\le
\binom{45}{5}
=
1\,221\,759.
}
\]

This is polynomial in \(L\) and independent of the potentially exponential
number of literal length-\(L\) words.

It is an upper bound on descriptor *types*, not a claim that the global
avoidance problem is polynomial-time.

# 9. Theorem CP3 — segmented generating operator

Let \(A_\sigma\) be the character-level finite-cutoff safety transition
operators.

For a fixed cut \(i\), introduce two commuting marker families
\(\mathbf x,\mathbf y\) and define

\[
\boxed{
\mathcal G_{L,i}(\mathbf x,\mathbf y)
=
\left(
\sum_{\sigma}x_\sigma A_\sigma
\right)^i
\left(
\sum_{\sigma}y_\sigma A_\sigma
\right)^{L-i}.
}
\]

Then

\[
\boxed{
[\mathbf x^u\mathbf y^v]\,
\mathcal G_{L,i}
=
\sum_{\substack{|b|=L\\
\Psi(\operatorname{pref}_i b)=u\\
\Psi(\operatorname{suf}_{L-i}b)=v}}
A_b.
}
\]

Thus each cut-profile family has an exact weighted transfer operator obtained
without enumerating the individual literal blocks in that family.

Internally unsafe blocks contribute the zero operator automatically in the
zero-dead safety representation.

For a profile-selected library, retain only coefficients satisfying the
declared full-profile condition

\[
u+v\in P.
\]

For a finite or regular arbitrary selected library, the same descriptor can be
carried through the library trie/DFA product.
