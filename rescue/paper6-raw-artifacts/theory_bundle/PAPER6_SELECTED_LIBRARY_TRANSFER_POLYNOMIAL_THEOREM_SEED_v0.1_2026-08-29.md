# PAPER 6 — SELECTED-LIBRARY TRANSFER POLYNOMIAL THEOREM SEED v0.1
**Date:** 2026-08-29  
**Status:** theorem seed + clean-room validation; not a manuscript

## 0. Central object

Fix a finite Abelian-avoidance cutoff \(K\).
Let \(S_K\) be an exact finite character-level safety automaton, with illegal
transitions represented by zero.

For each alphabet symbol \(\sigma\in\Sigma\), let

\[
A_\sigma
\]

be its transition matrix on \(S_K\).

For a word

\[
w=w_1\cdots w_L,
\]

write

\[
A_w=A_{w_1}\cdots A_{w_L}.
\]

Let \(B\subseteq\Sigma^L\) be any finite selected block library.

---

# 1. Theorem P6-L1 — selected-library transfer polynomial

Define

\[
\boxed{
M_{B,K}
=
\sum_{w\in B}A_w.
}
\]

Then the entry

\[
M_{B,K}(s,t)
\]

is exactly the number of blocks \(w\in B\) that can be appended safely to
history state \(s\) under cutoff \(K\) and end in state \(t\).

Therefore \(M_{B,K}\) is the exact one-block weighted transfer operator for the
selected library.

## Proof

For a deterministic zero-dead safety representation, \(A_w(s,t)=1\) exactly
when reading all letters of \(w\) from \(s\) remains safe and ends at \(t\);
otherwise it is zero.

Summing over \(w\in B\) counts exactly the legal selected blocks producing each
successor.

The same proof works with weighted block libraries by replacing each summand by

\[
\mu(w)A_w.
\]

---

# 2. Free noncommutative polynomial formulation

Let

\[
P_B
=
\sum_{w\in B}w
\]

be the characteristic polynomial of the library in the free associative
algebra on the alphabet.

The safety matrices give a representation

\[
\rho_K:\mathbb Q\langle\Sigma\rangle
\to
\operatorname{Mat}(S_K),
\]

and

\[
\boxed{
M_{B,K}=\rho_K(P_B).
}
\]

Thus a selected block library is an exact **noncommutative operator filter**
applied to the character-level avoidance dynamics.

This is standard weighted-automata/formal-series machinery. The Paper-6
research contribution, if successful, must come from the Abelian-avoidance
structure, profile decomposition, cutoff convergence, and scalable structural
construction—not from claiming this general algebraic representation as new.

---

# 3. Theorem P6-L2 — complete-library recoding

Let \(B_L^{\rm full}\) be the set of all internally safe length-\(L\) blocks.

Define

\[
A=\sum_{\sigma\in\Sigma}A_\sigma.
\]

Then

\[
\boxed{
M_{B_L^{\rm full},K}=A^L.
}
\]

## Proof

Expand

\[
A^L
=
\sum_{w\in\Sigma^L}A_w.
\]

If a length-\(L\) word is internally unsafe, its path contains a forbidden
factor independently of the incoming history, so

\[
A_w=0.
\]

Hence only internally safe words contribute, giving the stated sum.

## Meaning

This explains the complete-library calibration:

> a complete block library is just an \(L\)-step recoding of the underlying
> character-level finite-cutoff avoidance dynamics.

The genuinely new selected-library object appears when \(B\) is a proper
subset.

---

# 4. Theorem P6-L3 — profile generating operator

Introduce commuting markers \(x_\sigma\) and define

\[
\boxed{
\mathcal G_{L,K}(\mathbf x)
=
\left(
\sum_{\sigma\in\Sigma}x_\sigma A_\sigma
\right)^L.
}
\]

For a Parikh profile

\[
p=(p_\sigma)_{\sigma\in\Sigma},
\]

the coefficient

\[
\boxed{
[\mathbf x^p]\mathcal G_{L,K}
=
\sum_{\substack{w\in\Sigma^L\\\Psi(w)=p}}A_w.
}
\]

Because internally unsafe words evaluate to zero, this is exactly the transfer
operator of all safe length-\(L\) blocks having profile \(p\).

Therefore the profile-conditioned operators are coefficient matrices of one
multivariate matrix polynomial.

---

# 5. Corollary — profile-selected libraries need no literal block enumeration

Suppose the selected library consists of **all** internally safe blocks whose
profiles lie in a declared profile set \(P\).

Then

\[
\boxed{
M_{B,K}
=
\sum_{p\in P}
[\mathbf x^p]\mathcal G_{L,K}.
}
\]

Hence the operator can be generated by dynamic programming over:

- character position \(0,\ldots,L\);
- Parikh profile;
- safety state;

without enumerating the literal block list.

For a ternary alphabet there are only

\[
\binom{L+2}{2}
\]

possible length-\(L\) profiles.

At \(L=40\), this is

\[
\binom{42}{2}=861.
\]

This does **not** solve the safety-state explosion by itself, but it removes
literal block enumeration completely for profile-defined libraries.

# 6. Arbitrary finite or regular selected libraries

For an arbitrary finite literal library, \(P_B\) can be represented by a trie
or a minimized acyclic word automaton.

More generally, if the selected library is regular, its recognizer can be
combined with the character-level safety representation.

Dynamic programming over the library recognizer evaluates

\[
\rho_K(P_B)
\]

without iterating independently over every word whenever the recognizer shares
substructure.

This is again classical automata composition.

For Paper 6 it provides a clean universal input interface:

\[
\boxed{
\text{selected-library recognizer}
+
\text{Abelian safety representation}
\to
\text{exact block transfer operator}.
}
\]

---

# 7. Profile pushforward as homogeneous decomposition

The earlier profile-conditioned future operators are precisely the homogeneous
Parikh components

\[
M_{p,K}
=
[\mathbf x^p]\mathcal G_{L,K}
\]

for a complete/profile-selected library, or

\[
M_{B,p,K}
=
\sum_{\substack{w\in B\\\Psi(w)=p}}A_w
\]

for an arbitrary selected library.

The total selected operator is

\[
M_{B,K}=\sum_p M_{B,p,K}.
\]

This places the profile pushforward theorem and total-count dynamics inside the
same algebraic object.

# 8. Cutoff hierarchy

For each cutoff \(K\), the construction gives an exact finite selected-library
operator

\[
M_{B,K}.
\]

Let \(\lambda_{B,K}\) be the growth rate of its reachable recurrent block
language.

Because increasing \(K\) forbids more Abelian squares,

\[
\lambda_{B,2}
\ge
\lambda_{B,3}
\ge
\cdots
\ge
\lambda_B,
\]

and the previously established finite-cutoff theorem gives

\[
\boxed{
\lambda_{B,K}\downarrow\lambda_B.
}
\]

Thus the library-polynomial representation sits inside a certified convergent
scheme for the exact selected-library survival entropy.

# 10. Revised universal Paper-6 solver

For a finite selected block library or regular library specification:

1. choose cutoff \(K\);
2. build/represent the exact character-level Abelian safety dynamics;
3. represent the block library as a noncommutative polynomial, trie, DFA, or
   profile condition;
4. evaluate the selected-library operator \(M_{B,K}\);
5. optionally retain the profile components \(M_{B,p,K}\);
6. minimize only the semantics actually needed:
   - future language,
   - profile-weighted future,
   - total continuation counts,
   - Krylov/Hankel realization;
7. compute exact counts and spectral growth;
8. increase \(K\) for a certified monotone approach to exact survival entropy.

The remaining hard research problem is step 2/4 at large \(K,L\):

> exploit the Abelian boundary geometry so the safety representation and the
> operator evaluation do not require literal suffix-state explosion.

That is where Papers 4 and 5 can provide genuinely new structure.
