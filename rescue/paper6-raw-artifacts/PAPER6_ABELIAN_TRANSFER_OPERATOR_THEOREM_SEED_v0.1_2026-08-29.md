# 2. Theorem seed T-Delta — one unified crossing-square equation

Fix:

- a half-period `k >= 2`;
- an endpoint `j` inside the appended block;
- `1 <= j < 2k`.

Assume the history contains at least `2k-j` old characters.

The length-`2k` factor ending after the first `j` characters of the new block
is an Abelian square if and only if

\[
\boxed{
\Delta_{k,j}(s,b)=0,
}
\]

where

\[
\boxed{
\Delta_{k,j}(s,b)
=
S_{2k-j}(s)
-
2S_{(k-j)_+}(s)
+
2P_{(j-k)_+}(b)
-
P_j(b).
}
\]

Here

\[
x_+=\max(x,0).
\]

## Proof

### If `j <= k`

The crossing factor contains `2k-j` old characters and `j` new characters.

Its left half has Parikh vector

\[
S_{2k-j}-S_{k-j},
\]

and its right half has Parikh vector

\[
S_{k-j}+P_j.
\]

Their difference is

\[
S_{2k-j}-2S_{k-j}-P_j,
\]

which is the displayed formula because `P_0=0`.

### If `j > k`

The left half consists of all `2k-j` old characters plus the first `j-k`
new characters:

\[
S_{2k-j}+P_{j-k}.
\]

The right half is the remaining `k` characters of the new prefix:

\[
P_j-P_{j-k}.
\]

Their difference is

\[
S_{2k-j}+2P_{j-k}-P_j,
\]

again the displayed formula because `S_0=0`.

The factor is Abelian-square exactly when this Parikh difference is zero. ∎
