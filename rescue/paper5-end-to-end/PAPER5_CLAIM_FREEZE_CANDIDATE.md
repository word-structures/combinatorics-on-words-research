## Smallest Defensible Claim
**Verification-Guided Morphism Synthesis via Exact Parametric Parent Feasibility**

We present an exact algebraic constraint method that answers parent feasibility for partially specified uniform morphisms. By embedding fixed Parikh profiles into the Rao-Rosenfeld parent certificate framework, we construct prefix-Parikh reachable sets that eliminate invalid parent constraints before target images are fully enumerated. 

We do **NOT** claim:
- New template or substitution spectral theory.
- Exponential end-to-end speedup on all cases (the combinatorial CSP remains NP-hard).
- That the method eliminates all need for literal search.

We **DO** claim:
- The problem of testing whether an Abelian-power parent witness is realizable by *any* target word matching a fixed profile is solvable exactly and in polynomial time with respect to block length $.
- This parametric sieve inverts the standard construct -> certify pipeline into certify constraints while constructing, producing measurable branch pruning on exponentially growing candidate spaces.
