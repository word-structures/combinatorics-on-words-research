# 1. Setup

Let \(\Sigma\) be an alphabet of size \(d\). Let \(s\in\Sigma^*\) be an
arbitrary history and let \(x\in\Sigma^m\) be a proposed extension of fixed
length \(m\).

For \(1\le j\le m\), write

\[
P_j(x)=\Psi(\operatorname{pref}_j x).
\]

For a history suffix, write

\[
S_n(s)=\Psi(\operatorname{suf}_n s).
\]

We study repetitions that are **created by the extension**. Every such new
factor ends at some position \(|s|+j\) with \(1\le j\le m\).

The first theorem treats Abelian squares. A later theorem treats arbitrary
Abelian \(p\)-powers.

---

# 2. Theorem BE1 — exact long-square target formula

Fix a half-period

\[
k\ge m.
\]

A new Abelian square of half-period \(k\) ending \(j\) symbols into the
extension can exist only when

\[
2k-j\le |s|.
\]

Define

\[
\boxed{
R_{k,j}(s)
=
S_{2k-j}(s)-2S_{k-j}(s).
}
\]

Then the extension creates that Abelian square **if and only if**

\[
\boxed{
P_j(x)=R_{k,j}(s).
}
\]

## Proof

Let

\[
u=\operatorname{suf}_{2k-j}(s).
\]

Because \(k\ge m\ge j\), split \(u\) uniquely as

\[
u=AC,
\qquad |A|=k,
\qquad |C|=k-j.
\]

The candidate square ending \(j\) symbols into \(x\) has halves

\[
A
\quad\text{and}\quad
C\operatorname{pref}_j(x).
\]

These halves are Abelian equivalent exactly when

\[
\Psi(A)=\Psi(C)+P_j(x).
\]

But

\[
\Psi(C)=S_{k-j}(s)
\]

and

\[
\Psi(A)=S_{2k-j}(s)-S_{k-j}(s).
\]

Hence

\[
P_j(x)
=
S_{2k-j}(s)-2S_{k-j}(s)
=R_{k,j}(s).
\]

The converse is the same calculation read backwards. ∎

# 3. Corollary BE2 — finite target layers despite unbounded half-period

For every valid \((k,j)\),

\[
\boxed{
\sum_{a\in\Sigma} R_{k,j}(s)_a=j.
}
\]

Therefore only nonnegative \(R_{k,j}\) can match an extension prefix, and every
matchable target belongs to the finite composition layer

\[
\mathcal C_j(d)
=
\left\{
u\in\mathbb N^d:\|u\|_1=j\right\}.
\]

Its size is

\[
\boxed{
|\mathcal C_j(d)|
=
\binom{j+d-1}{d-1}.
}
\]

Define

\[
\boxed{
T_j(s)
=
\left\{
R_{k,j}(s):
 k\ge m,
 2k-j\le |s|,
 R_{k,j}(s)\ge0
\right\}.
}
\]

Although the half-period \(k\) is unbounded as histories become longer,

\[
\boxed{T_j(s)\subseteq\mathcal C_j(d)}
\]

for every history.

Thus all long-period square obstructions imposed on a bounded extension live in
finite target layers whose size depends on \((m,d)\), not on the history
length or on the largest half-period examined.

# 4. Theorem BE3 — long-period response saturation

Let \(B\subseteq\Sigma^m\) be any selected length-\(m\) extension library.
For \(j\) and \(u\in\mathcal C_j(d)\), predefine the universal/selected
prefix-profile cylinder

\[
B_{j,u}
=
\{b\in B:P_j(b)=u\}.
\]

Then the exact set of blocks that create **no new Abelian square with
half-period \(k\ge m\)** is

\[
\boxed{
\operatorname{Resp}_{\rm long}(s)
=
B\setminus
\bigcup_{j=1}^{m}
\bigcup_{u\in T_j(s)}
B_{j,u}.
}
\]

Hence the infinitely extensible family of long-period tests factors through the
finite obstacle signature

\[
\boxed{
T(s)=(T_1(s),\ldots,T_m(s)).
}
\]

for the purpose of the **current bounded extension response**.

This is a current-response theorem only. It does not say that \(T(s)\) can be
updated from itself after an extension.

# 5. Corollary BE4 — universal finite response-generator bound

The total number of universal prefix-profile obstacle vertices through depth
\(m\) is

\[
N(m,d)
=
\sum_{j=1}^{m}
\binom{j+d-1}{d-1}.
\]

By the hockey-stick identity,

\[
\boxed{
N(m,d)
=
\binom{m+d}{d}-1.
}
\]

Therefore the number of possible target signatures, and hence an upper bound on
the number of possible long-period response sets, is

\[
\boxed{
2^{\binom{m+d}{d}-1}.
}
\]

This should be compared with the unrestricted \(2^{d^m}\) possible subsets of
all \(d^m\) literal length-\(m\) words.

For fixed alphabet size \(d\), the response family is generated by only
polynomially many prefix-profile obstacle vertices.

For the ternary case,

\[
N(m,3)=\binom{m+3}{3}-1.
\]

At \(m=40\),

\[
\boxed{N(40,3)=12\,340.}
\]

This is a generator-count statement, not a claim that all \(2^{12340}\)
signatures are realizable.

# 6. Theorem BE5 — Parikh-prefix obstacle path formulation

The Parikh vectors of successive prefixes of a word

\[
x=x_1\cdots x_m
\]

form a directed lattice path

\[
0,
P_1(x),
P_2(x),
\ldots,
P_m(x)
\]

in the nonnegative composition DAG, with each step adding one coordinate unit
vector.

Theorem BE3 is equivalently:

> a length-\(m\) extension is long-period safe exactly when its Parikh-prefix
> path avoids the history-dependent obstacle set
> \(\bigcup_j T_j(s)\) at every level.

Thus unbounded historical Abelian-square constraints act on a bounded extension
as a finite **vertex-obstacle problem on the Parikh-prefix DAG**.

# 7. Theorem BE6 — exact noncommutative response-operator compiler

Let \(A_a\) be arbitrary noncommuting linear operators, or more generally
elements of any associative algebra with identity, indexed by
\(a\in\Sigma\).

For a word \(w=w_1\cdots w_j\), write

\[
A_w=A_{w_1}\cdots A_{w_j}.
\]

Define the obstacle-DP by

\[
H_0(0)=I,
\]

and for \(u\in\mathcal C_j(d)\),

\[
\boxed{
H_j(u)=0
\quad\text{if }u\in T_j(s),
}
\]

otherwise

\[
\boxed{
H_j(u)
=
\sum_{a\in\Sigma}
H_{j-1}(u-e_a)A_a,
}
\]

where nonexistent predecessor states contribute zero.

Then

\[
\boxed{
H_j(u)
=
\sum_{\substack{|w|=j\\P_j(w)=u\\
P_i(w)\notin T_i(s),\ 1\le i\le j}}
A_w.
}
\]

In particular,

\[
\boxed{
\sum_{u\in\mathcal C_m(d)}H_m(u)
=
\sum_{x\in\operatorname{Resp}_{\rm long}(s)}A_x.
}
\]

## Proof

Induct on \(j\). The claim is immediate for \(j=0\). Every length-\(j\) word
ending in letter \(a\) has a unique predecessor word of length \(j-1\) and
Parikh vector \(u-e_a\). Right multiplication by \(A_a\) preserves word order.
The obstacle test at level \(j\) removes exactly those paths whose new prefix
profile lies in \(T_j(s)\). Summing over all final letters gives the stated
recurrence. ∎

The number of coefficient states through depth \(m\) is

\[
\boxed{
\binom{m+d}{d},
}
\]

with at most \(d\) incoming recurrence terms per state.

Thus **once the target sets have been obtained**, the exact long-period
response-operator compilation stage uses polynomially many Parikh-prefix states
for fixed \(d\), rather than enumerating all \(d^m\) literal blocks.

This complexity statement deliberately excludes the cost of constructing the
history target sets and the cost of the operator algebra itself.

# 8. Corollary BE7 — regular selected libraries and local safety

If the extension library is specified by a DFA or another finite local safety
state, take the product of that state with the Parikh-prefix state \(u\).
Transitions rejected by the DFA contribute zero.

The same recurrence therefore compiles the exact weighted response operator for

- a regular selected block library;
- fixed local forbidden factors;
- short-half-period tests encoded in a finite local safety automaton;

while the target sets \(T_j(s)\) handle all half-periods \(k\ge m\).

This gives the exact structural split

\[
\boxed{
\text{bounded local extension automaton}
+
\text{unbounded-history / finite Parikh-obstacle interface}.
}
\]

No claim is made that the obstacle signature itself has a finite-state update.

# 9. Theorem BE8 — Abelian p-power generalization

Fix an exponent \(p\ge2\). A new Abelian \(p\)-power of root length
\(k\ge m\), ending \(j\) symbols into the extension, requires

\[
pk-j\le |s|.
\]

Write

\[
\operatorname{suf}_{pk-j}(s)
=
X_1X_2\cdots X_{p-1}Y,
\]

where

\[
|X_i|=k,
\qquad
|Y|=k-j.
\]

Then the new factor is an Abelian \(p\)-power if and only if there exists a
vector \(v\) such that

\[
\Psi(X_1)=\cdots=\Psi(X_{p-1})=v
\]

and

\[
\boxed{
P_j(x)=v-\Psi(Y).
}
\]

Again the target vector has coordinate mass \(j\). Hence all long-root
extension obstructions for a fixed Abelian exponent, or for any declared family
of Abelian exponents, use the **same universal prefix-Parikh obstacle layers**
\(\mathcal C_j(d)\).

The square theorem is the case \(p=2\).

# 11. Critical negative result — the finite response descriptor is not a state

The strongest dangerous overinterpretation would be:

> because \(T(s)\) is finite, the unbounded avoidance language is now
> finite-state.

That is false.

A counterexample exists inside the actual FULL-L4 aa2fr selected library using
safe block-aligned histories.

Take

```text
s = aaab | aaac
t = abbb | aaac
```

Both are globally safe under the project predicate. They have the same bounded
short suffix needed for local response checking and the same current long
obstacle signature.

Append the common selected block

```text
b = aaab.
```

Both extensions remain globally safe, but their successor obstacle signatures
differ.

Thus the current-response descriptor is **not update-closed**:

\[
\boxed{
\Theta(s)=\Theta(t),
\quad
b\text{ legal from both},
\quad
\Theta(sb)\ne\Theta(tb).
}
\]

This is not a startup-length artifact: the histories have equal length, are
block aligned, are built from the actual selected library, and are already safe.

The theorem therefore compresses the current action of unbounded history on a
bounded extension; it does not remove the unbounded history needed to update
that action.

# 12. Relation to the earlier bounded-defect theorem

The earlier Paper-6 bounded-defect theorem establishes

\[
\text{long-range bulk second difference}
+
\text{finite cut defect}
=0.
\]

That theorem is close in spirit to classical Abelian-template machinery and is
not being claimed as a new abstract mechanism.

The present result looks at the complementary **extension side**.
For a bounded extension, every long-root obstruction asks whether one of its
prefix Parikh vectors hits a history-generated target. Thus:

\[
\boxed{
\text{history side: unbounded additive/cut dynamics}
\longrightarrow
\text{finite target sets }T_j
\longrightarrow
\text{bounded extension: finite Parikh-prefix obstacle compiler}.
}
\]

Together these two interfaces give a possible new Paper-6 architecture without
using the v2.6--v3.4 rank identities as theorem hypotheses.
