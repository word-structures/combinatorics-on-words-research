# Word Structures — Research Publications

This directory is the project's reader-facing publication catalogue: the
stable, citable surface for papers the project has released.

It is not a source of truth. Each entry points to the canonical research
package that owns the paper — under `papers/paperN/` for packages that live in
this repository — and the canonical package wins wherever the two differ.
